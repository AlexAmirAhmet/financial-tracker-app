# Vela — задание проекта (опираться на него на всех этапах)

> Примечания по расположению и окружению:
> - Проект Vela лежит в папке `vela/` репозитория `financial-tracker-app`
>   (в корне репозитория — другое приложение на Expo, его не трогаем).
>   Все команды (`./gradlew ...`) выполняются из папки `vela/`.
>   Инструкции из корневых `AGENTS.md`/`CLAUDE.md` про Expo относятся к тому приложению, а не к Vela.
> - `local.properties` (путь к SDK) не коммитится: он у каждого компьютера свой.
>   В облачной среде SDK стоит в `/opt/android-sdk`; Android Studio на компьютере создаёт файл сама.
> - Общение с пользователем — на русском, простыми словами (пользователь не программист).

---

Создай с нуля Android-приложение «Vela» — видео- и аудиоплеер, который открывает практически любые форматы (по функциям уровня MX Player), с собственным пастельным дизайном. Приложение для личного использования (установка APK напрямую, не через Google Play). Я не программист: объясняй простыми словами, что сделано и что проверить на телефоне. Общайся со мной на русском.

Первым делом сохрани это задание в файл CLAUDE.md в корне проекта, чтобы опираться на него на всех этапах. Android SDK установлен через Android Studio — найди его путь сам и пропиши в local.properties (sdk.dir). Создай Gradle Wrapper, чтобы работала команда ./gradlew.

=== ТЕХНОЛОГИИ ===
- Kotlin, Jetpack Compose, Material 3. minSdk 26, targetSdk/compileSdk — последний стабильный.
- Один Gradle-модуль app. Код разложен по пакетам внутри com.vela.player: library, player, audio, stream, settings, data, ui/theme.
- Движок: libVLC для Android (org.videolan.android:libvlc-all, последняя стабильная 3.x — проверь актуальную версию). Он даёт все кодеки (MKV, AVI, HEVC, AC3, DTS, TrueHD, FLAC, APE, WMA), выбор аудиодорожек, встроенные и внешние субтитры, сетевые потоки.
- Размер APK: libVLC тяжёлый, поэтому собирай APK только под arm64-v8a (через abiFilters или ABI splits). Если понадобится поддержка старых 32-битных телефонов — отдельный APK под armeabi-v7a.
- Один экземпляр LibVLC на всё приложение (общий для видео и аудио), создаётся лениво.
- Фоновое аудио: foreground-сервис с MediaSessionCompat (androidx.media), медиа-уведомление, управление с экрана блокировки и гарнитуры. Media3 не используем: она завязана на ExoPlayer, а у нас libVLC.
- Room — позиции просмотра, плейлисты, история. DataStore — настройки (заводится на этапе 1, потому что настройки нужны уже на этапах 3–5).
- Медиатека через MediaStore, группировка по папкам (RELATIVE_PATH / BUCKET).
- Превью кадров: Coil с coil-video или MediaMetadataRetriever.

=== РАЗРЕШЕНИЯ И МАНИФЕСТ ===
- READ_MEDIA_VIDEO, READ_MEDIA_AUDIO, READ_MEDIA_VISUAL_USER_SELECTED (Android 14+, частичный доступ), READ_EXTERNAL_STORAGE (maxSdkVersion 32), POST_NOTIFICATIONS, FOREGROUND_SERVICE, FOREGROUND_SERVICE_MEDIA_PLAYBACK, INTERNET, WAKE_LOCK.
- MANAGE_EXTERNAL_STORAGE — необязательный «Полный доступ к файлам». Без него на Android 11+ приложение не видит файлы субтитров (.srt, .ass и т.д.) рядом с видео. Запрашивай его не при первом запуске, а когда он нужен (автоподхват субтитров, соседние файлы папки), с понятным объяснением; в настройках — переключатель с переходом в системный экран. Запасной вариант без этого доступа: выбор папки или файла через системный диалог (Storage Access Framework).
- RECORD_AUDIO — только для настоящей визуализации звука (системный Visualizer его требует). Запрашивай при первом открытии аудиоплеера с объяснением «нужно только для анимации столбиков, звук никуда не записывается». Если отказано — столбики работают как декоративная анимация в такт воспроизведению/паузе.
- Сервис воспроизведения: android:foregroundServiceType="mediaPlayback" (без этого атрибута на новых Android приложение упадёт).
- Активность видеоплеера: android:supportsPictureInPicture="true", android:resizeableActivity="true", configChanges для orientation|screenSize|screenLayout|smallestScreenSize|keyboardHidden, чтобы видео не перезапускалось при повороте и входе в PiP.
- Регистрация как обработчик ACTION_VIEW для video/* и audio/* со схемами content и file, а также для ссылок http/https/rtsp с медиа-MIME, чтобы файлы открывались «через Vela» из файлового менеджера и Telegram.
- Если пользователь на Android 14+ дал доступ только к части файлов — показать в медиатеке плашку «Видны не все файлы» с кнопкой «Разрешить доступ ко всем».

=== ДИЗАЙН ===
Стиль: нежный диагональный градиент фона, тонкие линейные иконки, блоки в тонкой тёмной рамке, серые полупрозрачные карточки, рукописные заголовки, круглая тёмная кнопка Play.

Светлая тема:
- Градиент фона 165° (в CSS-смысле: 0° — снизу вверх, отсчёт по часовой; направление ≈ сверху-слева вниз-вправо, почти вертикально). Для Compose пересчитай угол в точки start/end Brush.linearGradient с учётом размера экрана: #C8F1E2 0% → #F2EDF2 45% → #F2B9CB 82% → #E4C6E6 100%
- Текст: #1E1E24 основной, #3A3842 второстепенный, #55525E третичный
- Рамки блоков #1E1E24, толщина 1.5dp
- Карточки rgba(110,95,105,0.2); подложка круглых кнопок — #1E1E24 с альфой 12%
- Плашка формата (MP4, FLAC) #BFE0F2; акцентная точка и подчёркивание #8EC5E8
- Главная кнопка: фон #1E1E24, иконка белая

Тёмная тема:
- Градиент #173430 → #221F2A → #3D2433 → #2E2340 (те же позиции и угол)
- Текст #F1EEF3 / #D6D0DC / #B3ACBD, рамки #E9E4EE
- Карточки — белый с альфой 8%, плашка формата #2F4F63
- Главная кнопка: фон #F1EEF3, иконка #1E1E24

Шрифты (положить в res/font, оба с кириллицей, лицензия OFL; брать статические TTF, а не вариативные; файл лицензии OFL положить в проект):
- Caveat Bold — рукописные заголовки («привет», «сейчас играет», заголовки панелей), 32–60sp
- Montserrat Regular/Medium/SemiBold/Bold (400/500/600/700) — весь остальной текст: названия 13–14sp, подписи 10–12sp

Формы: блоки с рамкой — скругление 24dp, карточки — 20dp, чипы и кнопки — полностью круглые. Круглые кнопки 44–56dp, главная Play 74–76dp. Минимальная зона нажатия 44dp, отступы экрана 24dp. Учитывай edge-to-edge: контент не должен залезать под статус-бар и панель навигации.

Видеоплеер всегда на тёмном фоне кадра; его панели — светлые полупрозрачные «таблетки» (#F6F3F7, альфа 90%), нижняя панель управления — с горизонтальным пастельным градиентом.

=== ЭКРАНЫ ===
1. Медиатека: рукописное «привет» с голубым подчёркиванием, кнопки поиска и «+», текущая дата со стрелкой. Чипы «Все / Видео / Аудио / Папки». Блок «Продолжить просмотр» (последнее недосмотренное видео с полоской прогресса). Блок «Папки» — сетка в 4 колонки с линейными иконками и количеством файлов. Список файлов: превью или плашка формата, название, длительность, размер, полоска прогресса. Сортировка: имя, дата, размер, длительность. Внизу мини-плеер, если играет музыка (появляется на этапе 6).
2. Видеоплеер (по умолчанию ландшафт, поддерживает портрет; на планшетах Android 16+ система может игнорировать фиксацию ориентации — это нормально).
3. Панель «Субтитры / Аудио / Скорость / Экран» — выезжает справа (в портрете снизу).
4. Аудиоплеер: «сейчас играет», визуализация столбиками в рамке, плашка формата и качества (например FLAC 24/96; если разрядность неизвестна — только частота, например FLAC 96 кГц), перемотка, кнопки: перемешать, назад, Play, вперёд, повтор (выкл / вся очередь / один трек). Нижний блок: скорость, таймер сна, эквалайзер, очередь.
5. Сетевой поток: поле для ссылки (http, https, HLS m3u8, rtsp) и история ссылок.
6. Настройки: тема (светлая / тёмная / как в системе), декодер по умолчанию, автопереход к следующему файлу, вид субтитров, кодировка субтитров, скрытые папки, полный доступ к файлам.

=== ВИДЕОПЛЕЕР ===
- Жесты: вертикальный свайп в левой половине — яркость окна (screenBrightness), в правой — громкость (AudioManager). Горизонтальный свайп — перемотка с подсказкой вида «+0:23  1:13:03 / 2:49:03» (вся ширина экрана ≈ 3 минуты). Двойное касание слева/справа — ±10 секунд, по центру — пауза. Щипок — масштаб 100–300%. Одиночное касание — показать/скрыть управление, автоскрытие через 3 секунды. Жесты не должны срабатывать от системных свайпов у краёв экрана.
- Скорость 0,25×–4×, повтор A–B с метками на полосе перемотки, предыдущий/следующий файл папки, автопереход в конце.
- Предыдущий/следующий: для файлов из медиатеки — по той же папке через MediaStore. Для файлов, открытых из других приложений (content://), соседей может быть не видно — тогда кнопки неактивны, без ошибок.
- Режимы экрана: вписать, заполнить, растянуть, 100%, 16:9, 4:3. Поворот кнопкой. Блокировка касаний (остаётся только кнопка «Разблокировать»).
- «Картинка в картинке» и звук при сворачивании (при сворачивании без PiP воспроизведение передаётся в фоновый сервис).
- Декодер HW / HW+ / SW через опции libVLC.
- Запоминание позиции каждого файла; при открытии — сообщение «Продолжаем с 1:12:40» и кнопка «С начала». Ключ записи: путь к файлу, если он известен, иначе имя + размер + длительность — чтобы один и тот же фильм из медиатеки и из Telegram не считался двумя разными.
- Повреждённый или нечитаемый файл — понятное сообщение, без вылета.

=== СУБТИТРЫ И ДОРОЖКИ ===
- Встроенные дорожки субтитров и аудио — список с языком и кодеком.
- Внешние субтитры: автоматически подхватывать файл с тем же именем рядом с видео (требует полного доступа к файлам, см. раздел разрешений). Ручная загрузка через системный выбор файла: SRT, VTT, ASS/SSA, SUB (текстовый MicroDVD) и IDX+SUB (VobSub, картинки).
- Кодировка: автоопределение (в том числе Windows-1251 для русских субтитров) плюс ручной выбор кодировки в панели субтитров (опция libVLC subsdec-encoding). Русские субтитры в Windows-1251 должны читаться правильно.
- Настройки: размер, цвет, фон под текстом, задержка с шагом 0,1 с.

=== АУДИО ===
- Фоновое воспроизведение, уведомление с кнопками, управление с экрана блокировки и гарнитуры, пауза при отключении наушников (ACTION_AUDIO_BECOMING_NOISY), корректная работа с аудиофокусом (звонок, другое приложение).
- Очередь и плейлисты (создать, переименовать, удалить), перемешивание, повтор.
- Эквалайзер libVLC с пресетами: Обычный, Бас, Рок, Поп, Голос, Классика. Если во встроенных пресетах libVLC нет подходящего (например, «Голос») — задай полосы вручную.
- Таймер сна: 15, 30, 45, 60 минут или до конца трека. По окончании — плавное затухание звука за несколько секунд.
- Обложка из тегов файла, если есть; иначе визуализация столбиками.
