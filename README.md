# Долги

Мобильное приложение для учёта личных долгов на React Native (Expo, TypeScript, Expo Router).
Помогает отслеживать, кто должен вам, кому должны вы, сроки платежей и прогресс погашения.

## Стек

- Expo (managed workflow) + TypeScript
- Expo Router (файловая маршрутизация, headless `expo-router/ui` табы)
- Zustand + AsyncStorage (локальное хранение, без бэкенда)
- react-native-svg / expo-linear-gradient — для неоморфных эффектов

## Дизайн

Неоморфизм (soft UI): пастельный бело-голубой фон, купольные круглые элементы
(`DomeCircle`) с двойным слоем и мягким свечением, диффузные малоконтрастные тени.
Акценты: бирюзовый `#2fb8c9` — «мне должны», коралловый `#ff8a7a` — «я должен».
Шрифты: Poppins (заголовки/цифры) + Inter (текст). Интерфейс полностью на русском.

## Запуск

```bash
npm install
npx expo start
```

В выводе будут ссылки на запуск в Android-эмуляторе, iOS-симуляторе или Expo Go.

## Экраны

1. **Главная** — купольная кнопка с балансом, карточки «Мне должны» / «Я должен», ближайшие сроки
2. **Долги** — переключатель типа долга, список карточек
3. **Детали долга** — остаток, прогресс оплаты, история платежей, заметка
4. **Добавление долга** — тип, имя, сумма, срок, заметка
5. **Добавление платежа** — сумма, дата
6. **Настройки** — профиль, валюта, уведомления, экспорт данных, о приложении

## Структура

```
src/
  app/            экраны (Expo Router)
  components/     переиспользуемые UI-компоненты
  constants/      дизайн-токены (theme.ts)
  store/          Zustand store + AsyncStorage
  types/          типы данных
  utils/          форматирование валюты/дат
```
